# Description

This project is a web-based platform for creating and managing interactive quiz games, inspired by applications like **Kahoot**. It allows users to easily design question-based games, define answer options, set timers, and control scoring logic. Each game can have multiple steps (questions), and administrators can quickly create, edit, or delete them through an intuitive interface.

The platform includes real-time feedback for correct and incorrect answers, supports customizable messages, and provides an admin mode for game configuration. Its goal is to simplify the process of building fun and engaging quiz experiences for educational or entertainment purposes, without the need for external tools.
